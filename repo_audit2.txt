1. DUPLICATE MODULES  — the same module name in two places
------------------------------------------------------------------------------

  What this IS: two files you could edit, one of which is not running. Same
  problem as N numbered copies in a Downloads folder, one level up.

  What this is NOT (usually): a runtime hijack. Subdirectories are not on
  sys.path merely by existing, so `import X` from the repo root will NOT find
  a copy in subdir/X.py — the try/except fallback just fails. The hijack is
  real only when a script is run FROM INSIDE one of these directories, which
  puts that directory on sys.path[0] and lets its siblings win.
