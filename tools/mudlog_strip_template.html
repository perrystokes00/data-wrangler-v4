About this strip

Drag the dividers in the header to resize any column — widen the descriptions to read them, or the gas track to separate C1 from TG. Reset columns puts them back.

The scale slider is real feet-per-inch, not image zoom: the log is drawn from the data, so it stays sharp at any size and the text stays selectable. + / − or Ctrl-scroll also work, and the depth you are looking at is held while it rescales.

Everything here was written by the viewer — File → Export → Write all data to an ASCII file. Curve names, units and sample step; the ROP scale and the four depths it changes at; 703 coded lithology intervals; 22 coded oil shows; all three text tracks. Dashed red lines across ROP mark a scale change and say what it became.
